# SUQAENA
Independent premium women's fashion storefront for UAE & GCC.

## Run
Node.js 20+: `npm start`.

## Deployment
Railway Node service with start command `npm start` and health path `/health`.

## Important
This is a storefront preview. Checkout, inventory, shipping, COD and payment integrations are **not active**. Never commit API keys. Images are to be added under `public/assets/` before launch.
